IP Address Types
IPv4 recipient’s address may be a:
unicast,
broadcast,
multicast.
Additionally in IPv6 so-called anycasts have been introduced1.
1There will be a separate presentation on IPv6.

--- page 5 ---

Unicast
Represents a single destination.
In some implementations a single logical interface can have
assigned several IP addresses2 from the same or different
networks3.
ARP protocol translates IP addresses in the local network to
MAC addresses.
Important: interface MAC addresses (OUIs) always have the
first byte even!
2See: man ip-address .
3Several logical networks over a single physical segment.

--- page 6 ---

Broadcast
Represents all hosts of the network.
For security reasons routers block outgoing broadcasts so the
destination network is always local.
Recipient’s MAC address for a broadcast is always set to:
FF-FF-FF-FF-FF-FF.

--- page 7 ---

Multicast
Delivered to all hosts that participate in some service (e.g.
routing, media broadcasting etc).
A multicast group may contain hosts from several networks in a
single area.
First octets of multicast MAC addresses are odd (increased by 1).

--- page 8 ---

Multicast MAC - Example
OUI identifier for IEEE 802.1 is 00-80-C2.
IEEE 802.1 multicasts start with 01-80-C2.
Destination MAC address for BPDU packets (IEEE 802.1d) is
01-80-C2-00-00-00.

IP Address Structure
Written in the form: byte.byte.byte.byte .
Globally unique4.
Specifies the network number and the host number inside this
network.
First n bits(!) denote the network number and next (32 −n) bits
– host number.
All hosts within a network must have the same network number.
4Except so-called private addresses – see next chapters.

--- page 11 ---

Excluded Host Numbers
Addresses with all host bits equal to 0 denote network numbers.
The phrases: ’network 10.0.0.0’ and ’network 10’ are equivalent.
Addresses with all host bits equal to 1 are broadcast addresses
for their networks.
The address 255.255.255.255 is called a limited broadcast and it
is a local network broadcast.

History of Network Numbering
1 ARPANET: 1-byte network number and 3-byte host identifier.
2 Classful addressing: first byte of the IP address defines how
many bytes belong to the network part.
3 CIDR (Classless Inter-Domain Routing) based on the VLSM
(Variable Length Subnet Mask) allows specifying explicitly how
many first bits(!) identify the network.

--- page 16 ---

Variable Length Subnet Mask (RFC 950)
32-bit mask associated with every IP address; first n bits are
equal to 1 and next (32 −n) are equal to 05. Octets of the mask
are dot-separated and denoted using decimal or hexadecimal
notations.
net number = (IP address) AND (mask)
host number = (IP address) AND (NOT(mask))
Default masks are as follows:
for A class addresses: FF.00.00.00 (255.0.0.0)
for B class addresses: FF.FF.00.00 (255.255.0.0)
for C class addresses: FF.FF.FF.00 (255.255.255.0)
5We say that the mask is n bits long.

networks can be further divided into subnets

--- page 19 ---

Routing
Hosts don’t know masks / network numbers for other networks.
Datagram headers contain addresses but no masks / network
number information.
For local deliveries packets are send directly.
For non-local deliveries routers are responsible for finding proper
routes to remote destinations and passing datagrams along them.
Packet routing is fully transparent to both senders and recipients.

--- page 20 ---

Local vs Remote Recipient
Let the sender’s mask is n bits long.
The sender compares n first bits of its own and destination
addresses:
the same – recipient belongs to the same network (local delivery),
different – recipient belongs to a remote network (frames should
be addressed to the router).

--- page 21 ---

Classless Inter-Domain Routing (RFC 1518, 4632)
Simplifies routing thanks to prefix aggregation. There are single
entries for destinations with the same first bits (blocks).
Can be used for representing VLSM addresses.
Address shown in the CIDR format consists of the IP address
followed by slash and the number describing CIDR block length.
For interface addresses CIDR block lengths are equal to mask
lengths.

CIDR – Example
Prefix sub-delegation:
IANA grants 74.0.0.0/8 to RIPE,
RIPE gives 74.64.0.0/10 to Telekomunikacja Rurytańska S.A.,
Telekomunikacja Rurytańska S.A. sub-delegates 74.65.160.0/20
to Sokhatshev Internet Providers,
Tania Sieć Osiedlowa obtains 74.65.161.0/24 from Sokhatshev
Internet Providers.
Let’s assume a packet addressed to 74.65.161.63. External routers
need to know only the route to 74.64.0.0/10 border routers. No
knowledge about further sub-delegation / route is necessary
outside this block.

Subnet Numbering
IPs are global while subnets are local.
Keeping 0s close to the network-host dividing point as long as
possible is recommended. It allows further mask lengthening or
shortening while keeping IPs unchanged.

Loopback
The network 127/8 is called a loopback.
Local host is associated with any 127.x.x.x address.
The 127.0.0.1 address is resolved to the name localhost and it is
bound to the lo pseudo-interface.
Purpose:
testing TCP/IP stack,
using TCP/IP applications on isolated computers.

--- page 28 ---

Zeroconf (RFC 3927) and Other Reserved Blocks
(RFC 6890)
Interfaces not configured statically nor dynamically (for example
via the DHCP protocol) are configured automatically with the
169.254/16 prefix.
Informational document RFC 6890 lists some other blocks
excluded from the public address space by the IANA. Some of
them – reserved for experimental purposes – rejoin the public
address space thereafter.

Address Resolution Protocol
Having a destination IP we need destination MAC for:
the recipient (local delivery),
the router (remote delivery).
ARP broadcasts are sent for that purpose and unicast replies are
expected.
ARP replies (IP to MAC mappings) may be cached.
ARP is an extremely unsafe protocol. Alternatively static
mappings can be defined on a host.

TTL (Time To Live)
Time to live in hops (initially – in seconds). Every router decrements the
value of this field by 1. Packets with the TTL value equal to 0 are
eliminated; the ICMP Destination Unreachable packet should be sent to
the original sender. Initial value is OS-dependent.

Transmission Control Protocol
specified by the RFC 793 (1981)
transport layer protocol:
stream oriented
connection oriented
reliable
with flow control
requires establishing a session before any data transmission

--- page 20 ---

TCP Stream
unidirectional (two opposite streams per session)
identified by Initial Sequence Numbers (ISN)
each TCP packet contains Sequence Number: ISN + data offset
(in bytes, relative to the beginning of the stream)
each TCP ACK packet1 contains Acknowledgment Sequence
Number: next Sequence Number expected in the opposite stream
1See the next slide.

--- page 21 ---

Session Control Flags
Four flags in TCP headers are used for session control: SYN,
FIN, ACK and RST.
More than one flag can be set at a time.
The terms SYN packet, FIN packet etc. denote any TCP
packets with respective flags set.
Normally, all TCP packets (except the very fist one) are ACK
packets.

--- page 22 ---

TCP Session
opened by the three way handshake: SYN(→), SYN-ACK(←)
and ACK(→)
SYN packets define ISNs (because of offset equal to 0)
each packet must be confirmed with an ACK packet (otherwise it
is retransmitted) before the next one can be sent2
FIN packet closes a stream (it has to be confirmed with an ACK
packet)
both streams don’t have to be closed simultaneously3
2This can be changed with the SACK – Selective ACK – option set in Options.
3e.g. FTP data transfer.

--- page 23 ---

TCP States
RFC 793 defines TCP via a state transition diagram.
States change after receiving respective flags or flag combinations.
TCP connection is in one of the following states:
LISTEN,
SYN-SENT,
SYN-RECEIVED,
ESTABLISHED,
FIN-WAIT-1 (FIN sent),
FIN-WAIT-2 (FIN acknowledged),
CLOSE-WAIT (FIN received and acknowledged),
CLOSING,
LAST-ACK (FIN received, FIN sent) ,
TIME-WAIT,
CLOSE.

--- page 37 ---

TCP/UDP Ports
numbers managed by the IANA
the same assignments for TCP and UDP
address range is divided into 3 classes:
well-known ports (0 – 1023) – binding to well-known port
requires administrative (root) privileges
registered ports (1024–49151) may be used by user processes, for
example: browsers, readers, communicators etc
dynamic ports (49151–65534) often used for dynamic mappings
by simple NATs or other IP masquerades

--- page 39 ---

User Datagram Protocol
specified by the RFC 768 (1980)
extremely simplified protocol of the transport layer:
connectionless
unreliable
with no error correction nor ordering
intended for:
request-reply protocols that don’t require reliability such as DNS,
DHCP, RIP or NTP
protocols that provide their own control mechanisms (for
example: TFTP)
protocols used within LANs that require high efficiency (for
example: games)
